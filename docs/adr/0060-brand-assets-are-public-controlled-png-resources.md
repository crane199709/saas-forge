# 品牌素材使用公开读取的受控 PNG 资源

2026-10-14 第 4 阶段设计访谈确认：有效 Logo/favicon 作为可公开读取的品牌资料，任何知道平台生成素材 URL 的人均可读取图片；上传、替换及绑定仍受 Tenant 授权保护，只能绑定本 Tenant 素材，组织、成员与品牌管理数据继续受保护。素材使用受控同站 URL，不提供存储目录枚举，不接受任意外部 URL。

本决策在需要保密的媒体与可公开展示的品牌资料之间选择后者，明确不把不可猜测 URL 当作图片读取授权。MVP 输入限定为静态 PNG；具体大小和解码尺寸限制见[核心领域契约](../17-core-domain-contracts.md#tenant-品牌素材)。

违规素材引用永久禁用，后续读取拒绝；Tenant 管理员需上传合规新素材并重新保存 Profile，原 Profile 按既有原子品牌规则整份回退平台品牌。平台管理员不能代改品牌，也不承诺撤回已下载的图片副本。未绑定素材上传满 24 小时后清理，已替换或禁用素材在对应变更满 7 天后清理；当前有效 Profile 引用的素材保留。禁用素材留存期间仍不可公开读取，清理保留必要审计元数据。本决策不表示对象存储或素材管理已实现。
