# 分诊标签

工程 skills 使用五个标准分诊角色，本文件将角色映射到本仓库 Issue tracker 的实际标签。

| 标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由无人值守 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当 skill 提及分诊角色时，使用表中对应的仓库标签。需要调整标签命名时，编辑“仓库标签”列。
