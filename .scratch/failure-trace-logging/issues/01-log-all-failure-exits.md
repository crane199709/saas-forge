# 01: 补齐失败响应的追踪日志

Status: resolved

## 问题

租户 IP 允许列表校验返回 400 并展示 traceId，公共业务异常处理器却只记录 5xx，导致无法按页面 ID 查到日志。其他错误出口存在相同缺口。

## 修改范围

forge-sdk-core 的共享日志格式、forge-sdk-web 的响应及直接写出、forge-sdk-security 的安全错误写出、forge-gateway 的本地错误出口及相关测试。

## 验收

执行 [规格](../spec.md) 中的覆盖矩阵、敏感数据和去重断言；保持原有响应契约及跨服务追踪传播。
