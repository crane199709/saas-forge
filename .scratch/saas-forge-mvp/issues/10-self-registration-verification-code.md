# 10: 自主注册与验证码登录

**What to build:** 新用户可以在 tenant-app 自主注册 Identity（注册后尚未加入任何租户），也可以用手机或邮箱验证码登录。短信与邮件发送是可插拔 SPI，开发环境默认实现把验证码打印到日志。

**Blocked by:** 03 Tenant Realm 最小登录链路

**Status:** ready-for-agent

- [ ] 用户名/邮箱/手机号全局唯一；注册需验证邮箱或手机
- [ ] 验证码有有效期、发送频率限制与错误次数上限
- [ ] 手机/邮箱验证码登录与密码登录产出相同形态的 Token
- [ ] 短信与邮件发送为 SPI，提供开发用日志实现
- [ ] 新注册、无 Membership 的 Identity 登录后进入「无租户」页
- [ ] tenant-app 提供注册页与验证码登录方式
- [ ] 测试覆盖注册、重复注册、验证码过期、超频与错误次数上限
