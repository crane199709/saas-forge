# 09: 仓库外试点接入

**What to build:** 一个真实的内部团队在自己的仓库里，按接入指南，用正式发布的制品从零接入一个真实的 Business Service（如有界面，同时接入一个 Sub-App），部署到试点环境，并把遇到的问题反馈回平台。这是规格目标「SDK 能被仓库外团队真实接入」的最终验收。

**Blocked by:** 07 服务与 Shell 镜像, 08 模板冒烟 CI 任务；以及人工前提：仓库远端与 CI 密钥已配置，私有 Maven / npm / 镜像仓库已选定并完成首个正式版本发布，试点团队与试点服务已选定

**Status:** ready-for-human

- [ ] 选定试点团队与试点服务，记录在本工单
- [ ] 试点团队只依据接入指南与接入清单完成接入，不阅读平台源码；平台维护者只回答问题，不代为编码
- [ ] 试点服务部署到试点环境：经网关可访问，Manifest 上报成功，菜单与权限按角色生效，新建租户时完成幂等初始化
- [ ] 接入中遇到的每个问题都在对应规格目录下记为工单（SDK 缺陷、指南缺漏、新需求分开记录）
- [ ] 试点结束后在本工单 Comments 中记录：总耗时、各步骤耗时、卡点、指南缺漏，以及建议优先处理的问题
