# 03: 布局编辑组件与租户端菜单管理页

**What to build:** 按 [spec](../spec.md) 第 2、7 节，在 `@crane199709/ui` 实现可拖拽的布局编辑组件，并在租户端新增 `/menu-layout` 页面。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 写页面简报并经用户确认（[前端设计规范](../../../docs/agents/frontend-design.md)）
- [ ] 编辑组件：拖拽排序与跨分组移动，限制三层、页面不接收子节点；新建、重命名、删除自定义分组，删除时子节点移到原位置；清单分组不能改名或删除
- [ ] 编辑组件保存时保留目录外的引用：留在原父节点末尾，父节点不在则放顶层末尾
- [ ] 租户端页面：读取 `/navigation-layout`，目录为 Shell Page（首页、通知中心除外）与 `menus`；「保存」整棵提交，「恢复默认」二次确认；保存后刷新当前用户的权限与导航
- [ ] 路由与导航按 `iam:menu:manage` 显示，页面键为 `menu-layout`
- [ ] 组件测试覆盖 spec 第 8 节编辑组件与租户端管理页各项，文案走 i18n
- [ ] 设计走查：新增视觉用例并逐张查看截图
