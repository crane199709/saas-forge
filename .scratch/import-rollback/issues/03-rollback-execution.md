# 03: 回滚执行、保留期与审计

**What to build:** 按 [spec](../spec.md) 的“实现决策”，执行回滚：按记录恢复旧值、支持跳过冲突、失败可重试、快照 90 天过期、写审计。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 回滚只恢复快照中的字段值，不删除该次导入新增的行
- [ ] 支持 `skipConflicts`：冲突记录跳过并计入报告，不覆盖
- [ ] 按记录执行，记录成功/失败/跳过；重复执行幂等，已恢复的不重复处理
- [ ] 快照默认保留 90 天（可配置），过期由清理任务删除；过期后不可回滚
- [ ] 独立 Permission Code；审计 `io.importRollback` 记录任务号、恢复数、跳过数、失败数
- [ ] 测试覆盖：无冲突回滚、跳过冲突、重试、幂等、过期、权限拒绝、跨租户隔离
