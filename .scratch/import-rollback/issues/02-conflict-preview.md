# 02: 冲突检测与回滚预览

**What to build:** 按 [spec](../spec.md) 的“实现决策”，回滚前检查记录在导入后是否又被修改或被后续导入覆盖，并返回冲突报告。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 冲突判定覆盖：记录 `updated_at`/版本变化、后续导入对同一记录的覆盖
- [ ] 预览接口返回冲突记录清单、冲突原因、总数与可回滚数量
- [ ] 存在冲突时默认阻断，不自动执行回滚
- [ ] 快照过期时明确返回“不可回滚”，不返回空报告
- [ ] 测试覆盖：无冲突、被人工修改、被后续导入覆盖、快照过期
