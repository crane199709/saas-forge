# 09: 版本发布后只读消费复验

**What to build:** 在 0.2.0 制品由独立发布流程发布后，维护者可以从目标 Maven/npm 仓库只读消费实际已发布制品，确认最终仓库内容可供仓库外工程使用，并形成与发布准备证据相衔接的复验记录。范围以[规格](../spec.md)为准。

**Blocked by:** 08 升级质量门与发布准备验收；外部前置：目标 Maven/npm 仓库中的 0.2.0 制品已发布

**Status:** ready-for-agent

- [ ] 开始执行前核对外部发布已完成，记录发布标签、提交、实际制品版本和目标仓库；发布尚未完成时保留本票待执行状态，不代为发布。
- [ ] 复用现有只读消费入口，隔离本机 Forge 制品缓存影响，在仓库外消费目标仓库的实际已发布制品。
- [ ] Maven BOM 及所需 SDK 能正常解析；前端 SDK、UI、kit 可安装，既有类型使用、Vite 配置加载和 lint CLI 消费验证通过。
- [ ] 核对已发布制品与已验收候选的版本及来源，记录可核对的摘要或构建对应关系；出现差异时明确标出，不以候选验收替代发布后结果。
- [ ] 复验只读取、等待可用并消费既有制品，不重新 deploy、publish、覆盖同版本或移动标签；失败时记录具体原因，上传成功不能视为消费成功。
- [ ] 交付成功或失败的复验结论、执行材料和验证边界，说明这不是重新完成全部升级或部署验收；本票不构成工单 08 的前置条件。
