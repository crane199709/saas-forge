## Answer

`ExcelIo.template` 生成表头、列宽、必填标记与字典下拉；导入按名称唯一匹配可选项，转换后经 Bean Validation 与业务校验。有效 record 暂存 JSONL，全部通过后才进入单一事务逐行写入；任何错误均零写入并返回完整错误报告。覆盖编码拒绝、未知/重名名称、整数溢出、非法日期、行数上限、事务回滚与源文件清理。
