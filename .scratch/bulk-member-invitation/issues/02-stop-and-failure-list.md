# 02: 中途停止与失败清单

**What to build:** 为批量邀请补上发送中途的保护和失败行的修正重传。规则见 [spec.md](../spec.md) 第 5、6 节。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 发送期间弹窗不可关闭，刷新或关闭标签页时弹出浏览器离开提示，发送结束后解除
- [ ] 「停止」后已发出的请求等待完成，其余行标为未处理
- [ ] 失败清单含失败和未处理的行，格式与模板相同，末尾多一列「失败原因」
- [ ] 上传失败清单时忽略「失败原因」列，修正后可直接重传
- [ ] Vitest 覆盖停止和失败清单往返；Playwright 覆盖失败清单下载
