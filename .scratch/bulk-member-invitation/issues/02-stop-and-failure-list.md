# 02: 中途停止与失败清单

**What to build:** 为批量邀请补上发送中途的保护和失败行的修正重传。规则见 [spec.md](../spec.md) 第 5、6 节。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 发送期间弹窗不可关闭，刷新或关闭标签页时弹出浏览器离开提示，发送结束后解除
- [x] 「停止」后已发出的请求等待完成，其余行标为未处理
- [x] 失败清单含失败和未处理的行，格式与模板相同，末尾多一列「失败原因」
- [x] 上传失败清单时忽略「失败原因」列，修正后可直接重传
- [x] Vitest 覆盖停止和失败清单往返；Playwright 覆盖失败清单下载

## Comments

### 实现说明（2026-11-10）

- `sendInvitations` 增加 `stopped` 回调：worker 取下一行前检查，停止后不再发出新请求，已发出的照常等待，其余行结果为 `skipped`（未处理）。
- 发送中隐藏右上角关闭按钮并关闭 Esc、点遮罩关闭；「取消」换成「停止」，点击后显示「正在停止」直到在途请求完成。`beforeunload` 只在发送期间挂载，结束或卸载时移除。
- 结果计数增加「未处理」；失败明细与失败清单都含本地错误、接口失败和未处理行，按行号排序，未处理行的原因为「已停止，未发送」。
- `failureWorkbook` 与模板共用生成逻辑（含「填写说明」工作表），第一个工作表末尾多一列「失败原因」；`parseInvitations` 放行第 4 列表头为「失败原因」，并只读前三列判断空行，修正后可直接重传。
- 视觉基线：新增 `bulk-invitation-sending-{desktop,laptop}.png`；`bulk-invitation-result-*.png` 重新生成，因为多了「未处理」计数和「下载失败清单」。
