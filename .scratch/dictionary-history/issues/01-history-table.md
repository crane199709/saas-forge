# 01: 字典历史表与版本记录

**What to build:** 按 [spec](../spec.md) 的“实现决策”，新增字典变更历史表，并在有效变更后追加版本快照。

**Blocked by:** —

**Status:** ready-for-agent

- [ ] 历史表包含租户、服务、字典、版本号、完整覆盖快照、变更摘要、变更人与时间；带标准列与租户隔离
- [ ] 版本号按“租户 + 服务 + 字典”递增；快照是当时的租户覆盖集合
- [ ] 在新增、改名、改排序、停用、启用的有效变更后追加；无变化不追加
- [ ] Manifest 内置项不进入快照
- [ ] 接入租户清理
- [ ] 测试覆盖：有效变更、无变化、多次变更版本递增、跨租户隔离、清理
