# 03: 租户端角色页树形授权

**What to build:** 按 [spec](../spec.md) 第 4 节把租户端角色页的新建与编辑授权改为「菜单 → 操作」树加「功能权限」列表，提交仍为 Permission Code 列表。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 读取 `GET /roles/permission-tree` 渲染授权树与「功能权限」区
- [ ] 勾选叶子 = 授予其权限码；勾选分组 = 勾选全部子孙；不挂权限码的叶子显示「始终可见」且不可勾选
- [ ] 勾选 action 自动勾上所在页面；取消页面时其下 actions 一并取消
- [ ] 共用权限码的节点同步勾选，并提示与哪些菜单共用
- [ ] 每个 action 与功能权限区的权限码可单独勾选或取消，例如只授予查看与创建、不授予删除
- [ ] 编辑已有角色时按其权限码回显勾选状态
- [ ] 提交时去重为权限码列表，沿用 `PUT /roles/{id}/permissions` 与新建接口
- [ ] 文案走 i18n；单元测试覆盖勾选联动规则
