# 平台统一主题色

**Status:** ready-for-agent

## 目标

为当前仓库确立统一主题色，并让通过 sub-app-kit 创建的 Sub-App 继承同一规范。

## 已确认

- 2026-11-16：采用靛蓝 `#4F46E5` + Slate 中性色。
- 主色用于主要按钮、选中状态、链接与焦点；成功、警告、危险仍使用各自的语义色。
- 2026-11-16：本次只交付统一浅色主题，覆盖运营端、租户端、登录等入口页、现有示例 Sub-App 与新生成的 Sub-App，并同步 favicon 等品牌色。
- 不新增深色模式、产品切色入口或租户自定义主题。Sub-App 在 Shell 中继承主题，独立开发时使用同一套默认主题。

## 实现方案

### 配色

| 角色 | 默认颜色 | 使用方式 |
| --- | --- | --- |
| 品牌主色 | `#4F46E5` | 主要按钮、链接、选中与焦点 |
| 页面背景 | `#F8FAFC` | 内容面之外的页面底色 |
| 内容面 | `#FFFFFF` | 卡片、表格、弹窗、输入区域 |
| 标题与重要文字 | `#0F172A` | Element Plus primary text |
| 正文 | `#334155` | Element Plus regular text |
| 次级文字 | `#64748B` | Element Plus secondary text |
| 默认边框 | `#CBD5E1` | 输入控件等需要清晰轮廓的边框 |
| 浅边框与分隔线 | `#E2E8F0` | 表格、布局分隔 |
| 浅填充 | `#F1F5F9` | 辅助区域、悬停等中性背景 |

主色派生档位继续沿用现有 Element Plus 语义变量；其余中性色按 Slate 档位映射到现有 Element Plus 文字、边框、背景与填充变量。成功、警告、危险色沿用组件库现状。走查时检查按钮默认、悬停、按下、禁用与焦点状态的可读性。

本地 Element Plus 2.14.7 的实心 primary 按钮悬停使用 `primary-light-3`。现有混白 30% 的派生方式用于靛蓝时，白字对比度约为 3.41:1。因此保留 `light-3` 的浅色含义，在共享组件样式中统一覆盖实心主按钮的悬停背景与边框（主色混黑 10%），按下沿用 `dark-2`；不把 `light-*` 改成深色。正常、悬停与按下的实心主按钮白字对比度验收目标为至少 4.5:1；plain、link 等按钮保持各自状态语义。

### 唯一来源与继承

- 在共享 UI 的 `frontend/packages/ui/src/theme.ts` 集中维护默认配色，通过现有 `applyTheme` 写入完整主题。
- 两个 Shell 和 sub-app-kit 独立开发宿主调用同一入口，不在页面或生成模板复制一份色值。
- Sub-App 保持只读主题 token，不写文档根节点、不覆盖平台全局主题；局部样式使用现有 token。
- 保留诊断页已有的 alternate 切色探针，继续验证 Shell 与 Sub-App 共享主题；它不成为产品主题功能。
- 同步三个现有应用的静态 favicon 主色；后续生成工程通过脚手架规范继承品牌约定。

### 兼容与升级

- 保留现有 token 名称和三层归属；布局尺寸、间距、字号、圆角等取值不变。
- 修订 ADR-0029 和内部设计规范：token 名称保留，平台默认配色可在明确说明并完成视觉验收后统一演进。此次有意更新主色和中性色默认值。
- 已部署的 Sub-App 在 Shell 中读取宿主主题；仓库外工程的独立开发宿主要使用配套 UI/kit 版本并更新规范副本。已有页面写死的颜色不会自动变更，升级说明明确这一限制。
- 不自动修改、重新生成或发布仓库外工程。

### 文档与脚手架

同步 `docs/standards/sub-app.md`、内部前端设计规范、sub-app-kit 生成模板及规范副本、适用的后端 archetype 配套说明、`docs/business-service-guide.md` 和 `CHANGELOG.md`。后端脚手架只增加必要的前端配套指引，不引入前端依赖或无关功能。

既有 `Theme Token` 和 `Visual Baseline` 术语已准确覆盖本次需求，无需新增术语。

## 约束

- 保留现有 Theme Token 名称和三层契约；语义色沿用 Element Plus，不另建平行的颜色变量体系。
- 本次换色涉及旧默认色值的调整，需要在规范与变更说明中明确其与 ADR-0029「只加不改」约定的关系。
- 同步平台规范、sub-app-kit 模板、适用的后端脚手架说明、接入指南与 CHANGELOG。
- 现有工作区有视觉稳定性相关的未提交修改，实施时保留这些改动。

## 验收

- 主题单测：主色、中性色及派生色被写入预期变量；诊断切色后，中性色保持统一。
- 组件样式验证：实心主按钮默认、悬停与按下使用预期背景，白字对比度达到上述目标。
- 脚手架生成验证：新工程使用共享主题入口并携带新规范，不复制独立色板。
- 联邦 E2E：Sub-App 默认主色正确，Shell 切色时同步；独立开发宿主使用同样的默认配色。
- 运行相关 lint、类型检查和前端测试；遵守仓库串行执行工作区测试的现有约定。
- 在 1440 与 1024 宽度检查运营端、租户端、登录页及 Sub-App；确认主要按钮、导航选中、表格、弹窗与状态反馈的颜色。
- 因全局主题调整而受影响的视觉基线按现有 macOS 规范更新并逐张走查；保留其他任务的未提交修改。
