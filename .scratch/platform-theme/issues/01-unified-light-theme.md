# 01: 平台与现有 Sub-App 统一浅色主题

**What to build:** Operator 与 Membership 使用运营端、租户端、登录等入口页及现有示例 Sub-App 时，看到统一的靛蓝 + Slate 浅色主题。主题由宿主统一提供，主要按钮、导航选中、链接、焦点及品牌图标保持一致，同时保留成功、警告、危险等反馈的原有语义。

**Blocked by:** 无（可立即开始）。

**Status:** ready-for-agent

- [ ] 运营端、租户端、登录等入口页和现有示例 Sub-App 的品牌主色统一为 `#4F46E5`；页面背景为 `#F8FAFC`，内容面为 `#FFFFFF`。
- [ ] Slate 中性色统一映射到现有 Element Plus 语义变量：标题与重要文字 `#0F172A`、正文 `#334155`、次级文字 `#64748B`、默认边框 `#CBD5E1`、浅边框与分隔线 `#E2E8F0`、浅填充 `#F1F5F9`；其余必要中性色使用同一 Slate 色阶。
- [ ] 默认配色集中在共享 UI，两个 Shell App 与独立开发宿主使用统一主题入口；Sub-App 只读取 Theme Token，不另建平行语义色体系、不修改文档根节点或平台全局主题。
- [ ] 主色派生档位保留现有浅色与深色含义；实心主按钮的悬停背景及边框使用主色混黑 10%，按下沿用主色混黑 20%。默认、悬停和按下状态的白字对比度均至少为 4.5:1；plain、link 等按钮保持各自语义，禁用状态与焦点仍清晰可辨。
- [ ] 成功、警告、危险等语义色沿用现状；不新增深色模式、产品切色入口或租户自定义主题。
- [ ] 保留现有 Theme Token 名称和三层归属，布局尺寸、间距、字号、圆角等取值保持不变；诊断页原有 alternate 切色探针继续工作，切色不改变统一的中性色。
- [ ] 运营端、租户端与现有示例 Sub-App 的 favicon 同步为靛蓝品牌主色。
- [ ] 在同一变更中同步 Sub-App 页面规范、平台内部前端设计规范、ADR-0029、sub-app-kit 生成说明与规范分发、后端 archetype 的适用配套说明、业务服务接入指南及变更日志；明确保留 token 名称，默认配色可以在说明变更并完成视觉验收后统一演进。后端脚手架仅补必要指引。
- [ ] 主题单测验证主色、中性色、派生色与诊断切色后的结果；浏览器验证实心主按钮各交互状态的实际颜色与对比度，并验证 Shell App 切色后现有示例 Sub-App 同步。
- [ ] 相关样式检查、类型检查、格式检查和受影响的前端测试通过；工作区测试按现有串行执行约定运行。
- [ ] 在 1440 与 1024 两档宽度逐张查看受影响截图，覆盖运营端、租户端、登录页及示例 Sub-App 的导航、表格、弹窗与状态反馈。受影响的 Visual Baseline 按现有 macOS 生成及稳定性验收规范更新，交付时说明视觉变化。
- [ ] 保留工作区已有的视觉稳定性和其他未提交修改，不通过调整截图容差掩盖本次改动造成的问题。
