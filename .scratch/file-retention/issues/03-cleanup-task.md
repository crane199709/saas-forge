**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 清理任务在各业务服务内按 Tenant 运行，按用途分批处理
- [ ] 单个用途失败不影响其他用途；失败原因可观测
- [ ] 宽限期结束后删除 S3 对象与文件记录；删除失败保留记录并告警，不释放配额

- [ ] 审计 `storage.expire`、`storage.purge`、`storage.retentionExtend`；不记录文件内容
- [ ] 测试覆盖：完整生命周期、引用跳过、异常跳过、配额变化、审计事件
